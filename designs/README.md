# Design Drop Zone

Drop PNG screenshots or mockups here, then tell Claude what to implement.

## How to use

1. Drop one or more `.png` files into this folder
2. Tell Claude:
   - **"Implement the design in `designs/filename.png`"** — implement a specific file
   - **"Implement all designs in `designs/`"** — implement everything new in the folder
   - **"Implement the design in `designs/filename.png` for the Home screen"** — target a specific screen

## Tips

- Name files descriptively: `home-screen.png`, `paywall-redesign.png`, `budget-card.png`
- Multiple screens in one image are fine — Claude will split them out
- Annotate your PNG with arrows or labels to clarify intent
- Pair with context: "use the existing color palette" or "replace the current budget card"
